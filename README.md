# quasar-standard-candles

Research papers on whether quasars can be used as standard candles for the Hubble constant, via the X-ray to UV luminosity relation
(log L_X = γ log L_UV + β). Everything is reproducible from the public Lusso et al. (2020) catalog included here.

| Folder | What | Status |
|---|---|---|
| `paper1___no-evolution-review/` | Audit of the original draft "No Evidence for Redshift Evolution of the LX–LUV Relation" (Abu Seif 2026). Reproduces what is real, flags what is not. | done 2026-09-03 |
| `paper2___slope-drift-degeneracy/` | New paper: a cosmology-free, binning-free test of whether the slope γ drifts with redshift, and why "γ(z) is flat" cannot by itself prove standardizability in a flux-limited sample. | draft v1, 2026-09-03 |

Start with `AGENT.md` if you are an AI agent or want the fastest path. `manifest.json` indexes every file.

Authors: Nasser Abu Seif (NRIAG, Cairo) and Abdel-Rahman Nasser. Analysis code and drafting assisted by Claude (Anthropic); every number is script output, nothing is hand-typed.
